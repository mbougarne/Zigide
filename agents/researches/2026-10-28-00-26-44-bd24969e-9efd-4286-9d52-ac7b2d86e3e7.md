# Replication and confounding

Observable data: the measured consolidated run used429seconds against a297-second baseline. This does not identify how much host speed, cache state, changed trace inputs or scheduling contributed.

Illustrative calculation: an estimator predicts60seconds saved from a300-second run. If unrelated cold work adds120seconds, the observed result is360seconds. The setup saving can exist while the total result worsens. A single pair cannot identify each causal contribution; reporting only the job count would hide the outcome.

These example values are educational, not model telemetry or private reasoning. The task connection is to retract an unsupported performance recommendation while retaining verified controls. Repeated controlled measurements could separate effects, but spending substantial effort on a free low-consumption repository is outside the maintainer's priority.
