# Git tracking and reproducible generated evidence

A file can exist on disk without belonging to the current Git tree. `git rm --cached` removes its index entry while preserving the working copy. A root-specific ignore rule then prevents accidental staging of local artifacts; ignore rules alone cannot untrack already indexed files. Checking both file hashes and index membership verifies these distinct requirements.

Local files can hide broken documentation links, so exported-tree validation must omit the ignored directory. Generated benchmark data can remain available through a separate CI artifact while scripts and input fixtures stay tracked. Original timings cannot be reconstructed exactly by rerunning because hardware and scheduling affect observations; preserved local originals and historical commits remain evidence of the earlier run. This explanation describes observable commands and general verification practice, not model internals.
