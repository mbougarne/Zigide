# Distinguishing attempted delivery from confirmed delivery

A message-sending call is an observable attempt. A not-found response is evidence that delivery was not confirmed, so reporting it as sent would conflate intent and result. This task continued independent implementation and retained the status in its final output. The same distinction applies to a coverage-guided test runner that fails to compile: deterministic tests may pass, but the blocked campaign cannot be counted as executed. These are observable tool outcomes, not claims about hidden model internals.
