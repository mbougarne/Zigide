# AI research and learning

## Epistemic Boundary

## Observable Context

The user requested retirement of an AI reviewer. Git inspection located one workflow consuming a skill and two prompt-policy files. Repository rules and remaining CI were inspected.

## AI Concept

Dependency closure in agent planning: translate an outcome into a set of related artifacts, then check whether removing that set leaves a live consumer of an absent dependency. A generated plan is only a candidate until repository tools verify its edges.

## Worked Example

Illustrative graph: W is a review workflow; S is its skill; P its prompt; C its checklist; Q independent quality CI. Edges are W -> S, W -> P, W -> C.
Deleting only S leaves one broken dependency among three edges. Deleting {W,S,P,C} removes all three edges and leaves Q unchanged: 3 - 3 = 0 dangling edges. Four removed files do not imply four independent behaviors; they implement one integration.

## Connection to This Exchange

The observed workflow references supported removing its four-file dependency group. A tracked-source search checked for surviving consumers. This is observable tool grounding, not a claim about hidden model computation.

## Limits

A textual search can miss dynamically computed paths. Local absence does not prove the default branch is updated or a remote run succeeded.
