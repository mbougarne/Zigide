# Evaluating resource-saving claims

## Observable context

The workflow retains every job and cancels only superseded PR runs.

## Concept and worked example

Tool-grounded estimates must identify their denominator. For an illustrative workload, two 100-second validations overlap after the first has spent 20 seconds. Cancellation spends 20+100=120 seconds instead of 200. The saving is (200-120)/200=40%, not 50%. If the first job has already finished, saving is zero. An estimator that ignores overlap overstates the result.

## Connection and limits

This calculation explains how to qualify generated recommendations using observable execution data. These numbers are illustrative, not measured timings or model telemetry. Compare actual durations and cancellation frequency before claiming a budget reduction. Run history and GitHub concurrency/billing documentation were inspected.
