# Checkbox semantics and positive AI disclosure

An unchecked checkbox means its proposition is not affirmed. Checking the template's
Not applicable option would affirm no substantive AI assistance, which would be
false here. Keeping it unchecked is accurate; adding a positive AI-assistance line
makes the actual contribution clear.

AI-generated tests, passing CI and an AI privacy review do not establish completed
human review. The observed empty GitHub review list supports only the narrower
statement that no completed review is recorded on the PR. This explanation uses
observable UI/text/API state and does not present private model internals as evidence.
