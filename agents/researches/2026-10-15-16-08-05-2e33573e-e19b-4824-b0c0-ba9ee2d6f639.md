# Artifact retention and Git history

Keeping a document local requires both preserving its bytes and removing its current tracked representation. An ignore rule alone does not untrack an existing file. A normal removal commit removes it from the current branch tree while preserving the published history; history rewriting would be a separate destructive action. Library delivery has a separate persistent identity, which should be retained privately rather than copied into a public development ledger. These are observable data-lifecycle distinctions, not model internals.
