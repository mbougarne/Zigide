# Deduplicated command inventory

- `git log`: inspect prerequisite history.
- `git ls-remote`: verify current remote main.
- `git fetch`: obtain main without resetting the original checkout.
- `git worktree add`: create an isolated ticket branch.
- `git show`: inspect merged prerequisite contracts.
- `git diff`: inspect changes and whitespace.
- `git worktree list`: inspect existing worktrees.
- `cat`, `sed`, `rg`: inspect code, tickets, policy and installed Zig API definitions.
- `command -v`: locate existing tools.
- `mkdir`, `cat` with redirection: create source files and ignored notes.
- `ruby`: perform an in-place source-text edit; no Ruby runtime was added to the product.
- `zig fmt`: format and parse changed Zig source without compiling it.
- `zig version`: verify the installed toolchain.
- `git check-ignore`: confirm new internal notes are ignored.
- `git config --get`: inspect existing hook configuration without changing it.
