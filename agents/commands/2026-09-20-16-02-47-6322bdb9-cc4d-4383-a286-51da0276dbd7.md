# Commands: Diagnose Commit-Time Checks

- `sed` — inspect the provided workflow log, hook shim, README setup instructions, and CI workflow
- `rg` — find hook installation instructions and workflow triggers
- `git status --short` — inspect current worktree state
- `git branch --show-current` — identify the active branch
- `git log -5 --oneline --decorate` — identify the current commit and ancestry
- `git config --show-origin --get core.hooksPath` — inspect the configured hook directory
- `git rev-parse --git-path hooks` — resolve Git's default hooks directory
- `ls -la` — inspect installed and checked-in hook directories
- `git ls-files --stage` — confirm the tracked hook's mode
- `git show -1 --format=fuller --stat` — inspect the current commit metadata and changed files
- `git cat-file -e` — confirm the tracked hook exists in the current commit
- `test -x` — check whether the resolved local pre-commit hook is executable
- `date -u` — generate the trace timestamp
- `uuidgen` — generate the trace identifier
- `tr` — normalize the UUID to lowercase
