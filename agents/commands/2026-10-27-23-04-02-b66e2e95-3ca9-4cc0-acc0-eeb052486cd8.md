# Command inventory

- `git status`, `git remote`, `git diff`: inspect state, origin and focused patch.
- `git fetch`, `git worktree add`: isolate the default-branch change externally.
- `gh api`: read repository metadata, open PRs, Actions runs and jobs.
- Python standard-library scripts: parse bounded metadata, compute durations and edit workflow/trace files.
- `gh release download`: obtain the official workflow linter.
- `actionlint -shellcheck=`: validate workflow syntax and expression semantics; shellcheck is unavailable.
- `git diff --check`: check whitespace.
