## Agent Interpretation

The clarification "with zig" was read as: the custom scripts should be Zig programs, with shell reduced to the unavoidable hook shim. This makes the checker the repository's first real Zig code and gives the rules one implementation that runs identically locally, in the pre-commit hook, and in CI.

`mlugg/setup-zig@v2` was verified (via its Codeberg documentation) to resolve the Zig version from `minimum_zig_version` in `build.zig.zon` when no version input is given, so the zon file is the single source of truth for the toolchain pin; no separate version file was added.

Zig 0.16.0's `std.Io` overhaul removed `std.fs.cwd()`; the replacement API (`std.Io.Dir.cwd()` with an explicit `Io` instance from `std.Io.Threaded`) was confirmed by reading the installed standard library sources, and the checker was written against it and compiled to verify.

The package `fingerprint` was generated by the toolchain (first `zig build` reported the value), not invented.
